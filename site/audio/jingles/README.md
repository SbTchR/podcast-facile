# Musiques dédiées aux jingles

Les cinq styles Dynamique, Aventure, Historique, Mystère et Sérieux utilisent désormais les morceaux de jingle choisis sur Pixabay. Chaque morceau existe en arrangements de 25 et 35 secondes. Radio conserve Funky Chunk de Kevin MacLeod / Incompetech. Les musiques des versions précédentes sont gardées pour les projets déjà enregistrés.

Les nouveaux extraits raccourcissent ou répètent des phrases musicales avec des raccords courts, sans changer le tempo ni la hauteur. La fin musicale est ajustée et le niveau garde une marge avant saturation.

Les auteurs, sources, licences, adaptations, durées, paramètres et empreintes SHA-256 sont documentés dans `sources.json`. Les nouveaux arrangements peuvent être reproduits avec `app/scripts/prepare-jingle-beds.py /chemin/vers/les/originaux --version 5`. Les anciens fichiers et leurs informations de crédit restent disponibles pour les projets existants.

Le mixage du jingle ajoute les voix des élèves et ajuste le niveau de la musique pendant et après les paroles. Le parcours affiche les crédits et l’écran d’export permet de les télécharger pour accompagner la publication.
